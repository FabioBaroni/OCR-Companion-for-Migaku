Connect to the Mac app

Install OCR Companion for Migaku.app in Applications and open it once. Then click below. macOS may ask to open the app; approve the connection in its confirmation window.

Connect Mac app●

No copy and paste is needed for automatic setup.

Manual connection / troubleshooting

If the app does not open, move it into Applications and launch it once. Open Settings & setup… from the Mac app’s OCR menu, expand Manual connection & troubleshooting, paste the ID below into that window and click Connect Chrome extension.

Chrome launches the helper automatically when you read. No token file, local server or open Terminal window is required. Once the native test succeeds, you can stop the previous Terminal helper.

Images are processed in memory on your Mac. The helper registration allows only the extension ID you connect. Updating the extension at the same ID keeps the connection; changing its ID requires reconnecting.

Apple Live Text requires macOS 14 or later and supported Mac hardware. The helper checks support at runtime.

Automatic Migaku parsing on Bilibili manga

Experimental: creates a reading container before Migaku starts. This optional feature needs automatic page access only on manga.bilibili.com. It does not run OCR by itself or access your Migaku account. Other sites keep their existing behavior.
