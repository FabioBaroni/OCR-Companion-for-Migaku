## Recommended fix implemented

The extension's Next page action did not reliably advance Mangaben or Creative Comic. Native navigation did work: Mangaben's visible arrow reached interior prose, and Creative Comic's wheel scroll reached vertical Traditional Chinese narration. Version 1.5.2 marks both adapters `manualNavigation`, disables that extension action and labels it **Use reader page controls**. Reading, source/capture modes and optional selection remain available. After reload, both controls were verified disabled; Mangaben still captured the cover, and Creative Comic still read interior prose after native scrolling.

This is a small configuration correction, not an attempt to synthesize trusted page input or introduce browser-debugging permissions. Runtime changes are `adapters.json` (two flags), `manifest.json` and `content.js` (version 1.5.2). No new host permissions, adapter, native-helper change or OCR service. Tests now assert both the configuration and content-panel behavior, including refusal of a forced handler invocation.

## Validation and remaining work

All 10 JavaScript suites and 13 native protocol tests pass, including 37 deterministic capture scenarios, 40 lifecycle cases, all 22 adapter configurations/36 hostname-route fixtures, selection cancellation/cleanup, and the two corrected navigation controls. Packaged-source results are in VALIDATION.md and PACKAGED-REGRESSION-RESULTS.json. The same helper bytes and permissions are checked against 1.5.1; no personal token/allowlist files enter the ZIP.

This sweep mainly exercises normal zoom, reading after native scroll/page changes, and selected-area behavior on representative samples. The earlier regression report covers zoom/fullscreen, failures and deterministic races. It does not add a second physical Mac, exhaustive every-site zoom/fullscreen/keyboard/chapter-history tests, paid access, login-based readers or recognition-accuracy benchmarks. Native OCR still returns text without boxes, so exact speech-bubble-aligned OCR overlays remain unimplemented. Migaku selectable text/Shift integration is preserved in code; this sweep is not an all-site Migaku-known-word/highlighting revalidation.

Use the included one-command runner for future code changes. Beta testers can provide exact reader URL, language, mode, extension/helper versions, preview dimensions, and whether the pixels were actually visible before reading. They should omit credentials, helper pairing files and transient image-server tokens.
