# 1.0.0 beta 9 — Discord testing release

Includes the guided first-run setup, automatic Chrome-to-Mac pairing, one screen-recording permission step, connection status indicators, reader history, creator credits and the latest extension (1.6.9).

Fixes manual area selection when Migaku marks the comic viewer or page body as a sentence group. Actual Migaku controls and Shift lookup remain excluded from selection. The supplied Tonari recording demonstrates repeated area selection, OCR text, Migaku readings and dictionary lookups; an edited captioned demo is in 05-Demo.

The Mac app is universal (Apple Silicon and Intel), ad-hoc signed and not notarized. macOS 14+ and Apple Live Text support are required. Migaku is installed separately. No developer tools are needed to use the app.

Experimental: website audit entries describe the recorded sample tests, not a fresh guarantee for every reader or chapter. Setup on another Mac, the actual permission/restart transition, Intel hardware and multi-display configurations still need outside beta testing. No account, token or pairing configuration from the developer is included.
